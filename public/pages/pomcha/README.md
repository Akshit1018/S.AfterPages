# Pomcha – Tulsi Pink Cotton Skirt Set (AFTER / Modern Version)

Self-contained mobile product detail page recreation of the optimized "AFTER" design.

## Structure
```
pomcha-tulsi-pink/
├── index.html          # Main page
├── css/
│   └── styles.css      # All styles (CSS variables + components)
├── js/
│   └── main.js         # Gallery, selectors, CTAs, form, toast
├── assets/
│   ├── images/         # Place real product photos here
│   └── icons/          # Optional custom icons
└── README.md
```

## How to run
Open `index.html` in any modern browser (or serve via live server).

## Features implemented
- Announcement bar
- Sticky header with menu / logo / search / cart
- Breadcrumb
- Product gallery with dots + zoom lightbox
- Title, pricing (MRP + sale + save badge), star rating
- Color swatches (interactive)
- Size selector (interactive) + Size Chart link
- Dual CTAs: Add to Cart + Buy It Now (with feedback)
- Live Video Call card + Book Appointment
- Native <details> accordions: Description / Additional Info / Ask a Question (with form)
- Trust badges row
- Celebrities x Pomcha horizontal scroll
- Toast notifications
