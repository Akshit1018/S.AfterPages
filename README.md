# AFTER Pages — Open Source Brand Product Page Gallery

**AFTER Pages** is an open-source gallery of **high-craft product pages** — fashion, skincare, food, and more. Study the pages, copy the pattern when unlocked, and use it as a reference library for D2C brands.

[![License: MIT](https://img.shields.io/badge/License-MIT-fuchsia.svg)](LICENSE)

## Features

- Curated product-page gallery (Anayna, Pomcha, kōss, SaltWise, and others in the demo)
- Per-slug viewer
- Access / paywall demo (not a live payment rail)
- Useful as a **D2C landing page** moodboard you can run locally

> Brands shown are **design references in a demo**. Not official storefronts and not for resale of their assets.

## Who it is for

- D2C founders and e-commerce designers
- Agencies building **product detail pages**
- Developers collecting PDP layout patterns

## Quick start

```bash
git clone https://github.com/Akshit1018/S.AfterPages.git
cd S.AfterPages
npm install
VITE_AUTH_ENABLED=false npm run dev
```

Open [http://127.0.0.1:8080](http://127.0.0.1:8080).
